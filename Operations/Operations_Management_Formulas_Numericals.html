Plant Location - Formulas & Numericals

Break-Even Analysis
BEP (units) = F / (S - V)
Where:
F = Fixed Cost
S = Selling Price per unit
V = Variable Cost per unit
(S - V) = Contribution per unit
Total Cost at a Location
TC = Fixed Cost + (Variable Cost per unit x Quantity)
TC = F + V(Q)
Crossover Point (Between Two Locations)
F_A + V_A(X) = F_B + V_B(X)
Solve for X to find the production volume at which both locations have equal total cost.
Decision Rule: Below crossover - choose location with lower fixed cost; Above crossover - choose location with lower variable cost.
Problem 1 Break-Even Location Analysis

Problem Statement:

A company is considering two locations for a new plant:

  • Location X: Fixed Cost = Rs. 150,000, Variable Cost = Rs. 10/unit
  • Location Y: Fixed Cost = Rs. 350,000, Variable Cost = Rs. 8/unit

Determine which location is appropriate if expected demand is 130,000 units.

Given Data:
Parameter Location X Location Y
Fixed Cost (F) Rs. 150,000 Rs. 350,000
Variable Cost (V) Rs. 10/unit Rs. 8/unit
Solution:
1
Find Crossover Point

Set total costs equal:

F_X + V_X(Q) = F_Y + V_Y(Q)
150,000 + 10Q = 350,000 + 8Q
2
Solve for Q
10Q - 8Q = 350,000 - 150,000
2Q = 200,000
Q = 100,000 units
3
Decision Rule
If demand < 100,000: Choose Location X (lower fixed cost)
If demand > 100,000: Choose Location Y (lower variable cost)

Given demand = 130,000 units > 100,000 units
4
Verification
TC at Location X = 150,000 + 10(130,000) = Rs. 1,450,000
TC at Location Y = 350,000 + 8(130,000) = Rs. 1,390,000
Answer
Location Y is appropriate (Saves Rs. 60,000)
Centre of Gravity Method
C_x = (Sum of d_ix x W_i) / (Sum of W_i)
C_y = (Sum of d_iy x W_i) / (Sum of W_i)
Where:
C_x, C_y = Coordinates of centre of gravity
d_ix, d_iy = X and Y coordinates of location i
W_i = Weight or volume shipped to/from location i
Problem 2 Centre of Gravity Method

Problem Statement:

A company needs to locate a warehouse to serve 4 retail stores. Find the optimal location using Centre of Gravity method.

Given Data:
Store X-Coordinate Y-Coordinate Weight (tons/month)
A 100 200 500
B 300 100 300
C 400 300 200
D 200 400 100
Solution:
1
Calculate Sum of Weights
Sum W_i = 500 + 300 + 200 + 100 = 1,100 tons
2
Calculate C_x (X-coordinate)
Sum(d_ix x W_i) = (100 x 500) + (300 x 300) + (400 x 200) + (200 x 100)
= 50,000 + 90,000 + 80,000 + 20,000 = 240,000

C_x = 240,000 / 1,100 = 218.18
3
Calculate C_y (Y-coordinate)
Sum(d_iy x W_i) = (200 x 500) + (100 x 300) + (300 x 200) + (400 x 100)
= 100,000 + 30,000 + 60,000 + 40,000 = 230,000

C_y = 230,000 / 1,100 = 209.09

Weighted Factor Rating Method
Total Score = Sum of (Weight_i x Score_i) for all factors
Steps:
1. Identify important factors
2. Assign weights to each factor (total = 1.0 or 100)
3. Score each location for each factor (e.g., 1-100)
4. Calculate weighted score = Weight x Score
5. Sum weighted scores; Select location with highest total

Work Study - Formulas & Numericals

Basic Time Calculation
Basic Time = Observed Time x (Rating / 100)
Where:
Observed Time (OT) = Time recorded using stopwatch
Rating = Performance rating (100 = standard pace, >100 = faster, <100 = slower)
Standard Time Calculation
Standard Time = Basic Time + Allowances
OR
Standard Time = Basic Time x (1 + Allowance %)
Types of Allowances:
- Personal Allowance (5-7%)
- Fatigue Allowance (4-10%)
- Contingency Allowance (2-5%)
- Special Allowance (startup, shutdown, cleaning)
- Rework Allowance
Normal Time (Alternative Term)
Normal Time = Observed Time x (Rating / 100)
Normal Time and Basic Time are used interchangeably in time study calculations.
Problem 1 Basic Time Study Calculation

In a time study, observed time is 80 seconds and performance rating is 80%. Calculate the standard time if total allowance is 15%.

Given Data:

  • Performance Rating = 80%
  • Total Allowance = 15%
Solution:
1
Calculate Basic Time
Basic Time = Observed Time x (Rating / 100)
Basic Time = 80 x (80 / 100)
Basic Time = 80 x 0.80 = 64 seconds
2
Calculate Standard Time
Standard Time = Basic Time x (1 + Allowance %)
Standard Time = 64 x (1 + 0.15)
Standard Time = 64 x 1.15 = 73.6 seconds
Answer
Basic Time = 64 seconds | Standard Time = 73.6 seconds

Value Engineering - Formulas

Value Equation
Value = Function / Cost
Ways to Improve Value:
1. Same function at lower cost (Cost reduction)
2. Better function at same cost (Performance improvement)
3. Better function at lower cost (Ideal case)
4. Much better function at slightly higher cost
5. Slightly lower function at much lower cost
Value Index
Value Index = Function Worth / Function Cost
Interpretation:
- Value Index < 1: Poor value, needs improvement
- Value Index = 1: Fair value
- Value Index > 1: Good value

Value Engineering Job Plan Steps

Information Phase: Gather data - What is it? What does it do? What does it cost?
Analysis Phase: Function analysis - What should it do? What is the function worth?
Creative Phase: Brainstorming - What else can perform the function?
Evaluation Phase: Screen ideas - Which ideas are feasible?
Development Phase: Develop solutions - What will it cost? Will it work?
Presentation Phase: Present recommendations with cost-benefit analysis
Implementation Phase: Implement approved changes

Inventory Control & EOQ - Formulas & Numericals

Economic Order Quantity (EOQ)
EOQ = √(2 x D x Co / Cc)
Where:
D = Annual Demand (units/year)
Co = Ordering Cost per order (Rs./order)
Cc = Annual Carrying/Holding Cost per unit (Rs./unit/year)

Alternative: If Cc is given as percentage of unit cost:
Cc = Carrying Cost % x Unit Cost
Total Inventory Cost
Total Cost = Ordering Cost + Carrying Cost
TC = (Co x D/Q) + (Cc x Q/2)
Where:
D/Q = Number of orders per year
Q/2 = Average inventory level

At EOQ: Ordering Cost = Carrying Cost (costs are balanced)
Related EOQ Calculations
Number of Orders per Year = D / EOQ
Time Between Orders = EOQ / D (in years)
Reorder Point = Demand during Lead Time = d x L
Where: d = daily demand, L = lead time in days
Problem 1 Basic EOQ Calculation

Problem Statement:

A company has annual demand of 10,000 units. Ordering cost is Rs. 50 per order and carrying cost is Rs. 2 per unit per year. Calculate EOQ, number of orders, and total inventory cost.

Given Data:
  • Annual Demand (D) = 10,000 units
  • Ordering Cost (Co) = Rs. 50 per order
  • Carrying Cost (Cc) = Rs. 2 per unit per year
Solution:
1
Calculate EOQ
EOQ = √(2 x D x Co / Cc)
EOQ = √(2 x 10,000 x 50 / 2)
EOQ = √(1,000,000 / 2)
EOQ = √500,000
EOQ = 707.11 ≈ 707 units
2
Calculate Number of Orders per Year
Number of Orders = D / EOQ
Number of Orders = 10,000 / 707
Number of Orders = 14.14 ≈ 14 orders/year
3
Calculate Total Inventory Cost
Total Cost = (Co x D/Q) + (Cc x Q/2)
Total Cost = (50 x 10,000/707) + (2 x 707/2)
Total Cost = (50 x 14.14) + (2 x 353.5)
Total Cost = 707 + 707
Total Cost = Rs. 1,414
Answer
EOQ = 707 units | Orders/Year = 14 | Total Cost = Rs. 1,414
Problem 2 EOQ with Storage Constraint (From PPT)

Problem Statement:

Ashish keeps his inventory in special containers. Each container occupies 10 sq.ft. of store space. Only 5000 sq.ft. of storage space is available. The annual demand for the inventory item is 9000 containers, priced at Rs. 8 per container. The ordering cost is Rs. 40 per order, and the annual carrying costs amount to 25% of inventory value. Would you recommend to Ashish to increase his storage space? If so, how much should be the increase?

Given Data:
  • Available Storage = 5000 sq.ft.
  • Space per container = 10 sq.ft.
  • Maximum storage capacity = 5000/10 = 500 containers
  • Annual Demand (D) = 9000 containers
  • Unit Price (P) = Rs. 8
  • Ordering Cost (Co) = Rs. 40/order
  • Carrying Cost (Cc) = 25% of Rs. 8 = Rs. 2/unit/year
Solution:
1
Calculate EOQ
Cc = 25% x 8 = Rs. 2 per unit per year

EOQ = √(2 x D x Co / Cc)
EOQ = √(2 x 9000 x 40 / 2)
EOQ = √(720,000 / 2)
EOQ = √360,000
EOQ = 600 containers
2
Compare with Storage Capacity
EOQ = 600 containers
Current Max Storage = 500 containers
Shortfall = 600 - 500 = 100 containers
3
Calculate Additional Space Required
Additional containers = 100
Space per container = 10 sq.ft.
Additional space needed = 100 x 10 = 1000 sq.ft.
4
Cost Comparison
At Current Capacity (Q = 500):
TC = (40 x 9000/500) + (2 x 500/2) = 720 + 500 = Rs. 1,220

At EOQ (Q = 600):
TC = (40 x 9000/600) + (2 x 600/2) = 600 + 600 = Rs. 1,200

Savings = 1220 - 1200 = Rs. 20/year
Answer
Yes, increase storage by 1000 sq.ft. (to store 600 containers)
Annual savings = Rs. 20

Sequencing - Methods & Numericals

Johnson's Rule (n Jobs, 2 Machines in sequence AB)

List all jobs with processing times on Machine A and Machine B
Find the minimum processing time among all jobs on both machines
If minimum is on Machine A → Place job FIRST in sequence
If minimum is on Machine B → Place job LAST in sequence
Remove the job from list and repeat until all jobs are sequenced
Create timeline (Gantt chart) and calculate total elapsed time
Problem 1 Johnson's Rule - 5 Jobs, 2 Machines (From PPT)

Problem Statement:

There are 5 jobs, each of which has to go through machines A and B in the order AB. Determine the optimal sequence to minimize total elapsed time. Also find idle time for each machine.

Given Data:
Job J1 J2 J3 J4 J5
Machine A 2 4 5 7 1
Machine B 3 6 1 4 8
Solution:
1
Apply Johnson's Rule
Iteration 1: Min = 1 (J5 on A and J3 on B)
J5 has min on A → Place J5 FIRST
Sequence: [J5, _, _, _, _]

Iteration 2: Min = 1 (J3 on B) among remaining
J3 has min on B → Place J3 LAST
Sequence: [J5, _, _, _, J3]

Iteration 3: Min = 2 (J1 on A) among remaining
J1 has min on A → Place J1 next from front
Sequence: [J5, J1, _, _, J3]

Iteration 4: Min = 4 (J2 on A or J4 on B)
J2 has min on A → Place J2 next from front
Sequence: [J5, J1, J2, _, J3]

Iteration 5: Only J4 remains
Sequence: [J5, J1, J2, J4, J3]
2
Calculate Time Schedule
Sequence Job Machine A Machine B
In Out In Out

Machine A: Idle at end = 23 - 19 = 4 hours
(Machine A finishes at 19, total time is 23)

Machine B: Idle at start = 1 hour (waits for J5 from A)
B also has idle between jobs where it waits for A

Extended Johnson's Rule (n Jobs, 3 Machines in sequence ABC)

Applicability Condition:

Min(A) >= Max(B) OR Min(C) >= Max(B)

Conversion Method:

Check if conditions are satisfied
Create virtual machines: G = A + B, H = B + C
Apply standard Johnson's rule on G and H
Use the resulting sequence for all three machines

Statistical Quality Control - Formulas

Control Limits (3-Sigma)
UCL = Mean + 3σ (Upper Control Limit)
CL = Mean (Centre Line)
LCL = Mean - 3σ (Lower Control Limit)
99.73% of data falls within 3 standard deviations from mean in a normal distribution.
X-bar Chart (Mean Chart)
X̄ (Grand Mean) = Sum of sample means / Number of samples
UCL = X̄ + A₂R̄
LCL = X̄ - A₂R̄
A₂ is a factor depending on sample size (from tables):
n=2: A₂=1.880, n=3: A₂=1.023, n=4: A₂=0.729, n=5: A₂=0.577
R Chart (Range Chart)
R̄ (Average Range) = Sum of sample ranges / Number of samples
UCL = D₄ x R̄
LCL = D₃ x R̄
D₃ and D₄ are factors depending on sample size:
n=2: D₃=0, D₄=3.267 | n=3: D₃=0, D₄=2.575
n=4: D₃=0, D₄=2.282 | n=5: D₃=0, D₄=2.115
p-Chart (Proportion Defective)
p̄ = Total defectives / Total inspected
UCL = p̄ + 3√(p̄(1-p̄)/n)
LCL = p̄ - 3√(p̄(1-p̄)/n)
If LCL is negative, use LCL = 0
n = sample size
c-Chart (Defects per Unit)
c̄ = Total defects / Number of units inspected
UCL = c̄ + 3√c̄
LCL = c̄ - 3√c̄
Used for counting defects in a constant sample size.
If LCL is negative, use LCL = 0
Process Capability
Cp = (USL - LSL) / 6σ
Cpk = min[(USL - μ)/3σ, (μ - LSL)/3σ]
USL = Upper Specification Limit
LSL = Lower Specification Limit
Cp >= 1 means process is capable
Cpk >= 1.33 is generally desired

Theory of Constraints - Throughput Accounting

Core TOC Measures
Throughput (T) = Revenue - Truly Variable Costs
Investment (I) = Money tied up in system
Operating Expense (OE) = Money to turn I into T
Derived Measures
Net Profit = Throughput - Operating Expenses
NP = T - OE
Return on Investment
ROI = Net Profit / Investment
ROI = (T - OE) / I
Productivity
Productivity = Throughput / Operating Expenses
Productivity = T / OE
Investment Turns
Investment Turns = Throughput / Investment
Investment Turns = T / I
TOC Decision Priority (In Order):
  1. Increase Throughput (highest priority - unlimited potential)
  2. Reduce Investment
  3. Reduce Operating Expenses (limited - can't go below zero)

Demand Forecasting - Formulas & Numericals

Simple Moving Average
MA_n = (D₁ + D₂ + ... + D_n) / n
Average of last n periods' actual demand.
All periods have equal weight.
Weighted Moving Average
WMA = (w₁D₁ + w₂D₂ + ... + w_nD_n) / (w₁ + w₂ + ... + w_n)
Recent periods typically get higher weights.
Sum of weights should equal 1 (or 100%).
Exponential Smoothing
F_t = F_{t-1} + α(A_{t-1} - F_{t-1})
OR
F_t = αA_{t-1} + (1-α)F_{t-1}
α (alpha) = Smoothing constant (0 < α < 1)
- Low α (0.1-0.3): Stable demand, smooths fluctuations
- High α (0.4-0.5): Volatile demand, responds quickly to changes
Forecast Error Measures
Error (e) = Actual - Forecast = A - F
MAD = Σ|A - F| / n
MSE = Σ(A - F)² / n
MAPE = (Σ|A - F|/A × 100) / n
MAD = Mean Absolute Deviation
MSE = Mean Squared Error
MAPE = Mean Absolute Percentage Error
Problem 1 Exponential Smoothing Forecast

Problem Statement:

Given the following demand data, calculate forecast for period 6 using exponential smoothing with α = 0.3. Initial forecast F₁ = 100.

Given Data:
Period 1 2 3 4 5
Actual Demand 110 105 115 120 108

α = 0.3, F₁ = 100

Solution:

Using: F_t = F_{t-1} + α(A_{t-1} - F_{t-1})

1
Calculate Forecasts Step by Step
F₁ = 100 (given)

F₂ = F₁ + 0.3(A₁ - F₁)
F₂ = 100 + 0.3(110 - 100) = 100 + 3 = 103

F₃ = F₂ + 0.3(A₂ - F₂)
F₃ = 103 + 0.3(105 - 103) = 103 + 0.6 = 103.6

F₄ = F₃ + 0.3(A₃ - F₃)
F₄ = 103.6 + 0.3(115 - 103.6) = 103.6 + 3.42 = 107.02

F₅ = F₄ + 0.3(A₄ - F₄)
F₅ = 107.02 + 0.3(120 - 107.02) = 107.02 + 3.89 = 110.91

F₆ = F₅ + 0.3(A₅ - F₅)
