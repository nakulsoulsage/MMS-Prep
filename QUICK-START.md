## 🚀 3 STEPS TO SUCCESS

### Step 1: Copy the Prompt (30 seconds)

1. Open: `scripts/claude-code-prompt.md`
2. Copy the entire prompt template
3. Replace these placeholders:
   ```
   {{STUDENT_NAME}} → Your Name
   {{TOPIC_NAME}} → Your Topic (e.g., "Marketing Analytics")
   {{MODULE_1_TITLE}} → Your First Module
   [Continue for all 8 modules...]
   ```

**OR** use the template config:

1. Copy: `configs/template-config.json` → `configs/your-topic.json`
2. Fill in your details
3. Reference it in the prompt: "Use config: configs/your-topic.json"

### Step 2: Generate with Claude Code (2-3 minutes)

1. Open Claude Code
2. Paste your customized prompt
3. Press Enter
4. Wait while Claude creates your comprehensive guide

### Step 3: Study! (12 weeks)

Your guide is ready in `generated/` folder!

Open it in browser and start learning! 📚
