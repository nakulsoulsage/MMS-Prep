## 🚀 Quick Start (First Time)

### Step 1: Clone This Repo
```bash
git clone https://github.com/YOUR_USERNAME/MMS-Prep.git
cd MMS-Prep
```

### Step 2: Open in Claude Code
```bash
# Open Claude Code in this directory
```

### Step 3: Say "START"
```
START
```

### Step 4: Answer 3 Questions
Claude will ask:
1. What topic?
2. Your name and background?
3. Your goal?

### Step 5: Get Your Guide!
Your comprehensive study guide will be generated in `generated/` folder!
