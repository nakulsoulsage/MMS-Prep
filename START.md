# 🚀 START - Simple 3-Question Guide Generator

**Just answer 3 questions and get your comprehensive study guide!**

---

## HOW TO USE:

1. **Clone this repo** (one time):
   ```bash
   git clone https://github.com/YOUR_USERNAME/MMS-Prep.git
   cd MMS-Prep
   ```

2. **Open Claude Code** and say: **"START"**

3. **Answer 3 simple questions** - That's it!

---

## THE 3 QUESTIONS:

When you say "START", Claude will ask you:

1. **What topic?**
   - Example: "Marketing Analytics" or "Operations Management"

2. **Your name and background?**
   - Example: "Nakul, worked in AI automation and analytics at SoulSage"

3. **What's your goal?**
   - Example: "Summer internship in Equity Research"

**Then Claude automatically creates your complete study guide!**
