Find Two Missing Frequencies Using Mean and Total Frequency

Descriptive Statistics

Key Formulas

Mean for Grouped Data
x̄ = Σfm / Σf
Midpoint of Class Interval
m = (Lower Limit + Upper Limit) / 2

Variables Explained:

  • x̄ = Arithmetic Mean
  • f = Frequency of each class
  • m = Midpoint of class interval
  • Σf = Total frequency (N)
  • Σfm = Sum of (frequency × midpoint)

Solution Steps:

  1. Calculate midpoint (m) for each class interval: m = (L + U) / 2
  2. Set up equation 1: Sum of all frequencies = Total frequency (N)
    Σf = known frequencies + x + y = N
  3. Set up equation 2 using mean formula:
    Mean × Σf = Σfm
    Substitute values and express in terms of x and y
  4. Solve the two simultaneous equations to find x and y

From Your Assignment:

Given: Mean = 26, Total Frequency = 80

Equation 1: x + y = 35 (from total frequency)

Equation 2: 15x + 35y = 955 (from mean formula)

Solution: x = 13.5, y = 21.5

Find Two Missing Frequencies Using Median and Total Frequency

Descriptive Statistics

Key Formulas

Median Formula for Grouped Data
Median = L + ((N/2 - CF) / f) × h

Variables Explained:

  • L = Lower boundary of median class
  • N = Total frequency
  • N/2 = Position of median
  • CF = Cumulative frequency of class preceding median class
  • f = Frequency of median class
  • h = Class size (width)

Solution Steps:

  1. Set up equation 1: Sum of frequencies = Total (N)
  2. Find N/2 to locate median class
  3. Build cumulative frequency column
  4. Identify the median class (where CF first exceeds N/2)
  5. Apply median formula and set equal to given median
  6. Solve the two simultaneous equations

From Your Assignment:

Given: Median = 46, Total Frequency = 70

Median class: 40-60 (since N/2 = 35 falls here)

L = 40, h = 20, f = 30, CF = 5 + x

46 = 40 + ((35 - (5+x)) / 30) × 20

Solution: x = 21, y = 4

Quartiles and Percentiles

Descriptive Statistics

Key Formulas

General Position Formula
Value = L + ((Position - CF) / f) × h
Quartile Positions
Q1 Position = N/4 | Q2 Position = 2N/4 | Q3 Position = 3N/4
Percentile Position
Pk Position = (k × N) / 100

Variables Explained:

  • Q1 = First Quartile (25th percentile)
  • Q2 = Second Quartile (Median, 50th percentile)
  • Q3 = Third Quartile (75th percentile)
  • Pk = kth Percentile
  • N = Total frequency
  • CF = Cumulative frequency of preceding class

Solution Steps:

  1. Calculate cumulative frequencies
  2. Find the position: For Q3 = 3N/4, For P77 = 77N/100
  3. Locate the class where this position falls
  4. Apply the interpolation formula

From Your Assignment:

For Q3: Position = 3×70/4 = 52.5 (falls in 40-60 class)

Q3 = 40 + ((52.5 - 26) / 30) × 20 = 57.67

For P77: Position = 77×70/100 = 53.9

P77 = 40 + ((53.9 - 26) / 30) × 20 = 58.6

Standard Deviation (Step Deviation Method)

Measures of Dispersion

Key Formulas

Step Deviation
d = (m - A) / h
Standard Deviation (Step Deviation Method)
σ = h × √[(Σfd²/Σf) - (Σfd/Σf)²]

Variables Explained:

  • A = Assumed mean (usually midpoint of middle class)
  • h = Class size (width)
  • d = Step deviation = (m - A) / h
  • m = Midpoint of each class
  • fd = Frequency × deviation
  • fd² = Frequency × deviation squared

Solution Steps:

  1. Calculate midpoint (m) for each class
  2. Choose assumed mean (A) - typically middle class midpoint
  3. Calculate d = (m - A) / h for each class
  4. Calculate fd and fd² columns
  5. Find Σf, Σfd, and Σfd²
  6. Apply the standard deviation formula

From Your Assignment:

Wages distribution: A = 550, h = 100, Σf = 50

Σfd = -33, Σfd² = 99

σ = 100 × √[(99/50) - (-33/50)²]

σ = 100 × √[1.98 - 0.4356] = 124.27

Coefficient of Variation (CV)

Measures of Dispersion

Key Formula

Coefficient of Variation
CV = (σ / x̄) × 100

Variables Explained:

  • CV = Coefficient of Variation (expressed as %)
  • σ = Standard Deviation
  • x̄ = Mean (arithmetic average)

Important Interpretation:

Lower CV = More Consistent (less variability relative to mean)

Higher CV = Less Consistent (more variability relative to mean)

CV is useful for comparing variability between datasets with different units or means.

From Your Assignment:

Plant Mean (x̄) σ CV Calculation CV
Plant A 250 units 25 units (25/250) × 100 10%
Plant B 280 units 30 units (30/280) × 100 10.71%

Conclusion: Plant A has lower CV (10% < 10.71%), so Plant A shows greater consistency.

Pearson's Correlation Coefficient

Correlation & Regression

Key Formula

Pearson's Correlation Coefficient (r)
r = [NΣXY - (ΣX)(ΣY)] / √{[NΣX² - (ΣX)²][NΣY² - (ΣY)²]}

Variables Explained:

  • r = Correlation coefficient (-1 to +1)
  • N = Number of data pairs
  • X, Y = Variables being correlated
  • ΣXY = Sum of products of X and Y
  • ΣX² = Sum of X squared
  • ΣY² = Sum of Y squared

Interpretation of r:

Value of rInterpretation
r = +1Perfect positive correlation
0.7 to 0.99Strong positive correlation
0.4 to 0.69Moderate positive correlation
0.1 to 0.39Weak positive correlation
r = 0No correlation
r = -1Perfect negative correlation

From Your Assignment:

Data: N=5, ΣX=365, ΣY=385, ΣX²=27375, ΣY²=30273, ΣXY=28780

r = [5×28780 - 365×385] / √{[5×27375 - 365²][5×30273 - 385²]}

r = 3375 / 3385.41 = 0.997

Interpretation: Very strong positive correlation - aptitude test is an excellent predictor of job performance.

Spearman's Rank Correlation Coefficient

Correlation & Regression

Key Formula

Spearman's Rank Correlation (rs)
rs = 1 - [6Σd² / N(N² - 1)]

Variables Explained:

  • rs = Spearman's rank correlation coefficient
  • d = Difference between ranks (R1 - R2)
  • d² = Squared difference
  • Σd² = Sum of squared differences
  • N = Number of paired observations

Solution Steps:

  1. Assign ranks to each variable (if not already ranked)
  2. Calculate d = R1 - R2 for each pair
  3. Square each d to get d²
  4. Sum all d² values to get Σd²
  5. Apply the formula

From Your Assignment:

Marketing firm ranking data: N = 7, Σd² = 16

rs = 1 - [6×16 / 7(49-1)]

rs = 1 - [96 / 336] = 1 - 0.286 = 0.714

Interpretation: Strong positive correlation between Group X and Group Y rankings - they agree on feature importance.

Simple Linear Regression

Correlation & Regression

Key Formulas

Regression Equation
ŷ = a + bX
Slope (b)
b = [NΣXY - (ΣX)(ΣY)] / [NΣX² - (ΣX)²]
Y-Intercept (a)
a = Ȳ - bX̄

Variables Explained:

  • ŷ = Predicted value of Y
  • a = Y-intercept (value of Y when X = 0)
  • b = Slope (change in Y per unit change in X)
  • X̄ = Mean of X values (ΣX/N)
  • Ȳ = Mean of Y values (ΣY/N)

Solution Steps:

  1. Create columns: X, Y, X², XY
  2. Calculate ΣX, ΣY, ΣX², ΣXY
  3. Calculate slope b using the formula
  4. Calculate means: X̄ = ΣX/N, Ȳ = ΣY/N
  5. Calculate intercept: a = Ȳ - bX̄
  6. Write regression equation: ŷ = a + bX
  7. To predict: substitute X value into equation

From Your Assignment:

Student study hours vs exam scores: N=5

ΣX=27, ΣY=370, ΣX²=175, ΣXY=2170

b = [5×2170 - 27×370] / [5×175 - 27²] = 860/146 = 5.89

X̄ = 5.4, Ȳ = 74

a = 74 - 5.89×5.4 = 42.19

Regression equation: ŷ = 42.19 + 5.89X

For X = 6 hours: ŷ = 42.19 + 5.89(6) = 77.53

F-Test for Comparing Two Variances

Hypothesis Testing

Key Formulas

F-Statistic
F = S²larger / S²smaller = S²A / S²B

Variables Explained:

  • S²A = Sample variance of group A (numerator)
  • S²B = Sample variance of group B (denominator)
  • df1 = Degrees of freedom numerator = nA - 1
  • df2 = Degrees of freedom denominator = nB - 1

Solution Steps:

  1. State Hypotheses:
    H₀: σ²A = σ²B (variances are equal)
    H₁: σ²A > σ²B (variance A is greater)
  2. Calculate F-statistic (larger variance in numerator)
  3. Determine degrees of freedom: df1 = n₁ - 1, df2 = n₂ - 1
  4. Find F-critical from F-table at given α
  5. Decision: Reject H₀ if Fcalculated > Fcritical

F-Critical Values (Common):

df1, df2α = 0.05α = 0.01
20, 152.333.37
10, 102.984.85

From Your Assignment:

Portfolio A: n=21, S²=9.8 | Portfolio B: n=16, S²=4.2

F = 9.8 / 4.2 = 2.333

df1 = 20, df2 = 15, α = 0.05

Fcritical(0.05, 20, 15) = 2.33

Since 2.333 > 2.33, Reject H₀

Conclusion: Portfolio A has significantly greater variance (risk) than Portfolio B.

One-Sample t-Test (Unknown Population SD)

Hypothesis Testing

Key Formula

t-Statistic
t = (X̄ - μ₀) / (s / √n)

Variables Explained:

  • X̄ = Sample mean
  • μ₀ = Hypothesized population mean
  • s = Sample standard deviation
  • n = Sample size
  • df = Degrees of freedom = n - 1

When to Use t-Test:

  • Population standard deviation (σ) is unknown
  • Sample size is typically small (n < 30)
  • Population is approximately normally distributed

t-Critical Values (Two-Tailed):

dfα = 0.05α = 0.01
14±2.145±2.977
20±2.086±2.845
30±2.042±2.750

From Your Assignment:

Screw lengths: X̄ = 9.85cm, μ₀ = 10.0cm, s = 0.5cm, n = 15

H₀: μ = 10.0cm | H₁: μ ≠ 10.0cm | α = 0.01

t = (9.85 - 10.0) / (0.5 / √15) = -0.15 / 0.129 = -1.163

df = 14, tcritical(0.01, 14) = ±2.977

Since |-1.163| < 2.977, Fail to reject H₀

Conclusion: No significant evidence that mean differs from 10.0cm standard.

One-Sample Z-Test (Known Population SD)

Hypothesis Testing

Key Formula

Z-Statistic
Z = (X̄ - μ₀) / (σ / √n)

Variables Explained:

  • X̄ = Sample mean
  • μ₀ = Hypothesized population mean
  • σ = Population standard deviation (KNOWN)
  • n = Sample size

When to Use Z-Test:

  • Population standard deviation (σ) is known
  • Sample size is large (n ≥ 30) OR population is normal

Z-Critical Values:

Test Typeα = 0.05α = 0.01
Two-Tailed±1.96±2.576
One-Tailed (Right)+1.645+2.33
One-Tailed (Left)-1.645-2.33

From Your Assignment:

Bolt strength: X̄ = 148.5kg, μ₀ = 150kg, σ = 5kg, n = 36

H₀: μ = 150kg | H₁: μ ≠ 150kg | α = 0.01

Z = (148.5 - 150) / (5 / √36) = -1.5 / 0.833 = -1.80

Zcritical(0.01, two-tailed) = ±2.576

Since |-1.80| < 2.576, Fail to reject H₀

Conclusion: No significant evidence that mean strength differs from 150kg.

Chi-Square Test for Independence

Hypothesis Testing

Key Formulas

Expected Frequency
E = (Row Total × Column Total) / Grand Total
Chi-Square Statistic
χ² = Σ[(O - E)² / E]
Degrees of Freedom
df = (Rows - 1) × (Columns - 1)

Variables Explained:

  • O = Observed frequency
  • E = Expected frequency
  • χ² = Chi-square statistic
  • df = Degrees of freedom

Solution Steps:

  1. State Hypotheses:
    H₀: Variables are independent (no relationship)
    H₁: Variables are not independent (relationship exists)
  2. Calculate row and column totals
  3. Calculate expected frequency for each cell: E = (Row × Col) / Total
  4. Calculate (O - E)² / E for each cell
  5. Sum all values to get χ²calculated
  6. Find df = (r-1)(c-1) and lookup χ²critical
  7. Decision: Reject H₀ if χ²calc > χ²critical

χ² Critical Values:

dfα = 0.05α = 0.01
13.8416.635
25.9919.210
37.81511.345
49.48813.277

Gender vs Shopping Channel (In-store/Online): 2×2 table, n = 200

Chi-Square Goodness of Fit Test

Hypothesis Testing

Key Formulas

Expected Frequency (Uniform Distribution)
E = N / k (where k = number of categories)
Chi-Square Statistic
χ² = Σ[(O - E)² / E]
Degrees of Freedom
df = k - 1

Variables Explained:

  • O = Observed frequency
  • E = Expected frequency
  • N = Total observations
  • k = Number of categories
  • df = k - 1

Solution Steps:

  1. State Hypotheses:
    H₀: Data follows the expected distribution (e.g., uniform)
    H₁: Data does not follow the expected distribution
  2. Calculate expected frequencies (E = N/k for uniform)
  3. Calculate (O - E)² / E for each category
  4. Sum to get χ²calculated
  5. Find df = k - 1 and lookup χ²critical
  6. Decision: Reject H₀ if χ²calc > χ²critical

From Your Assignment:

Customer service requests across 5 weekdays: Total = 500

DayMonTueWedThuFri
Observed (O)1109580105110
Expected (E)100100100100100
(O-E)²/E1.000.254.000.251.00

χ² = 1.00 + 0.25 + 4.00 + 0.25 + 1.00 = 6.50

df = 5 - 1 = 4, χ²critical(0.05, 4) = 9.488

Since 6.50 < 9.488, Fail to reject H₀

Conclusion: Requests are distributed uniformly across weekdays.

Paired t-Test (Dependent Samples)

Hypothesis Testing

Key Formulas

Mean Difference
d̄ = Σd / N
Standard Deviation of Differences
Sd = √[(Σd² - (Σd)²/N) / (N-1)]
t-Statistic (Paired)
t = d̄ / (Sd / √N)

Variables Explained:

  • d = Difference between paired observations (X₂ - X₁)
  • d̄ = Mean of differences
  • Sd = Standard deviation of differences
  • N = Number of pairs
  • df = N - 1

Solution Steps:

  1. State Hypotheses:
    H₀: μd = 0 (no difference)
    H₁: μd ≠ 0 (significant difference)
  2. Calculate d = X₂ - X₁ for each pair
  3. Calculate d² for each pair
  4. Find Σd and Σd²
  5. Calculate d̄ = Σd / N
  6. Calculate Sd using the formula
  7. Calculate t-statistic
  8. Compare with tcritical (df = N-1)

From Your Assignment:

Fertilizer comparison: N = 10 plots

Σd = 27, Σd² = 125

d̄ = 27/10 = 2.7

Sd = √[(125 - 729/10) / 9] = √[52.1/9] = 2.406

t = 2.7 / (2.406/√10) = 2.7 / 0.761 = 3.549

df = 9, α = 0.05, tcritical(0.05, 9) = 1.833 (one-tailed)

Since 3.549 > 1.833, Reject H₀

Conclusion: New fertilizer significantly increases crop yield.

Quick Reference: Which Test to Use?

Situation Test Key Indicator
Compare sample mean to known value, σ KNOWN Z-Test Population SD given
Compare sample mean to known value, σ UNKNOWN t-Test Sample SD given, small n
Compare two sample variances F-Test Two variances given
Before/After or Matched pairs Paired t-Test Same subjects, two measurements
Test if observed fits expected distribution χ² Goodness of Fit One variable, categories
Test relationship between two categorical variables χ² Independence Contingency table (rows × columns)
Measure linear relationship strength Pearson's r Numerical data, linear relationship
Compare rankings Spearman's rs Rank/ordinal data
Predict Y from X Regression Find equation Y = a + bX
